# Rúbrica — Desarrollo Web Integral

**Valor del proyecto**: 60% del parcial
**Entrega**: exposición 3-4 agosto 2026, Auditorio Docencia 3
**Requisito**: "El proyecto deberá ser desarrollado por los equipos formados en clase, a partir del proyecto realizado en cuacuatrimestres pasados"

## Unidad temática
- III. Integración de componentes de software para aplicaciones web
  - I.1 Especificación de principios de codificación segura
  - I.1 Implementación de web services en el desarrollo web
- III. Pruebas y liberación del desarrollo web
  - I.1 Despliegue de servicios
  - I.2 Pruebas de software
  - I.3 Liberación del software

## Criterios de exposición (lista de cotejo)
| # | Criterio | Valor |
|---|---|---|
| 1 | Interfaz de autenticación funcional (al menos 1 rol) | 10% |
| 2 | Al menos dos módulos completamente funcionales | 30% |
| 3 | Diseño (UI) de pantallas/interfaces | 10% |
| 4 | Alojado en un servidor (pasar el link el día de la exposición) | 10% |
| 5 | Explicar 2 pruebas de software: Caja Negra y Caja Blanca | 20% |
| 6 | Todos los integrantes deben exponer correctamente | 20% |

## Qué falta hacer para cumplirla
- [ ] Documentar principios de codificación segura aplicados (helmet, JWT, bcrypt, rate-limit ya existen — falta documentarlos como tal)
- [ ] Especificar formalmente los web services (ya existen como API REST — falta la "especificación" académica)
- [ ] Desplegar en servidor real con link público
- [ ] Preparar ejemplo concreto de prueba de caja negra y caja blanca sobre el sistema
- [ ] Repartir quién expone qué parte
