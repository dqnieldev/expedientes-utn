# 🧠 Vault — Proyecto Paperless System (expedientes-utn)

Este vault es el contexto central del proyecto para el equipo IDGS-91,92,93,94 y para cualquier agente de IA (Claude, OpenCode, etc.) que ayude a desarrollarlo. Léelo en este orden si eres un agente nuevo en el proyecto:

1. [[Vision-General]] — qué es el proyecto y qué se necesita este cuatrimestre
2. [[Stack-Tecnologico]] — con qué está construido
3. [[Roles-y-Permisos]] — ALUMNO / ADMIN / DEVELOPER
4. Rúbricas en `02-Cuacuatrimestre-Actual/` — los tres entregables exactos que se califican
5. Notas en `04-Modulos/` — el trabajo técnico dividido por frente

## Estructura

```
00-Proyecto/           → identidad del proyecto, stack, roles (estable, cambia poco)
01-Cuacuatrimestre-Anterior/ → lo que ya está construido y funcionando
02-Cuacuatrimestre-Actual/   → las 3 rúbricas tal cual las dieron los profesores
03-Decisiones/         → registro corto de decisiones técnicas (ADRs)
04-Modulos/            → una nota por frente de trabajo activo
05-Modelo-Datos/       → esquema Prisma y diccionario de datos
06-Planificacion/      → cronograma y tareas pendientes
_Plantillas/           → plantillas para notas nuevas
```

## Regla de oro para mantener el vault útil

Notas cortas y enlazadas, no un archivo gigante. Cuando termines una tarea o tomes una decisión, actualiza la nota correspondiente — no dejes que el vault se desactualice, porque de eso depende que el agente entienda el estado real del proyecto.
