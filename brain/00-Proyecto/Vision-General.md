# Visión general del proyecto

**Nombre**: Paperless System (repo `expedientes-utn`)
**Institución**: Universidad Tecnológica de Nayarit — Ing. en Desarrollo y Gestión de Software
**Grupo**: IDGS-91 (rúbricas compartidas con 92, 93, 94)
**Cuacuatrimestre**: Mayo - Agosto 2026 (segundo periodo)
**Fecha de exposición**: 3 y 4 de agosto de 2026, Auditorio Docencia 3

## Qué es

Sistema institucional para digitalizar y gestionar expedientes de alumnos: los alumnos suben sus documentos (Acta, CURP, Certificado, Constancia), los administrativos los validan (aprueban o rechazan con motivo), eliminando el proceso en papel.

## Qué se construyó el cuatrimestre pasado

Ver [[Modulo-Expedientes]] — sistema web completo (frontend React + backend Node/Express/Postgres) con los tres roles, flujo de validación de documentos, respaldos automáticos, notificaciones por email y auditoría.

## Qué pide este cuatrimestre

Tres materias evalúan el mismo proyecto desde tres ángulos distintos — ver `02-Cuacuatrimestre-Actual/`:

- **Desarrollo Web Integral** → seguridad, servicios web, pruebas, despliegue
- **Dispositivos Inteligentes** → app Android + Wear OS que consume el sistema
- **Extracción del Conocimiento en Base de Datos** → módulo de analítica sobre los datos del sistema
