# Stack tecnológico

## Frontend web
| Tecnología | Uso |
|---|---|
| React 18 + Vite | Framework y bundler |
| TailwindCSS | Estilos y diseño responsivo |
| Axios | Peticiones HTTP |
| React Router DOM | Navegación y rutas protegidas |
| react-i18next | Internacionalización (ES/EN) |
| Lucide React | Iconografía |

## Backend
| Tecnología | Uso |
|---|---|
| Node.js + Express | Servidor y API REST |
| PostgreSQL 18 | Base de datos relacional |
| Prisma ORM | Modelado y consultas a BD |
| JWT | Autenticación con tokens |
| bcryptjs | Hash de contraseñas |
| Nodemailer + Gmail | Envío de correos |
| node-cron | Tareas programadas (respaldos) |
| archiver | Compresión ZIP |
| express-validator | Validación de inputs |
| helmet | Headers de seguridad HTTP |
| morgan | Logs de peticiones |
| express-rate-limit | Limitación de intentos de login |
| multer | Manejo de archivos subidos |

## Por definir este cuatrimestre
- **Android**: Kotlin/Java + Android Studio (a decidir) — consumirá la API REST existente vía Retrofit/OkHttp
- **Wear OS**: módulo companion del app Android (Wearable Data Layer API)
- **Analítica**: Python (pandas, scikit-learn) o R — a decidir en [[Modulo-Analitica]]
- **Despliegue**: servidor pendiente de elegir (Render, Railway, VPS) — exigido por la rúbrica de Desarrollo Web

Ver [[Backend-API]] para el detalle de endpoints ya existentes.
