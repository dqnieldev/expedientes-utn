# Workflow: contexto del proyecto

Antes de cualquier tarea nueva:
1. Lee brain/README.md para ubicarte en la estructura del proyecto
2. Si la tarea es de un módulo específico, lee la nota correspondiente en brain/04-Modulos/
3. Si la tarea toca una rúbrica, lee brain/02-Cuatrimestre-Actual/
4. Si tomas una decisión técnica relevante, propón una nota nueva en brain/03-Decisiones/
